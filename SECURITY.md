Security Policy
Reporting a Vulnerability
Please do not report security vulnerabilities through public GitHub issues.

Use GitHub's private vulnerability reporting feature to report suspected security vulnerabilities privately.

Please include:

A description of the vulnerability
Steps to reproduce the issue
The potential impact
Relevant configuration or environment information
Any suggested remediation, if known
Security reports will be reviewed and assessed for appropriate remediation.

Supported Versions
This repository is maintained for demonstration and testing purposes. Security fixes are applied to the current version of the project.
